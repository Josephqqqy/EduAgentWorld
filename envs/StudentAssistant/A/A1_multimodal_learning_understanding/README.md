## 环境目标

模拟学生上传题目图片、教材页、实验图或语音材料后，系统完成区域检测、文字/公式识别、低置信度确认、结构化学习对象创建和题库匹配。图片来自固定 fixture，保证任务可复现；不保证每张图片都能精确匹配题库。

## 状态链

```text
上传 → 检测区域 → 识别 → 检查置信度 → 确认/修正 → 创建学习对象 → 匹配题目
```

## 文件布局

- `raw/`：固定的图片、PDF、音频和快照。
- `normalized/`：实体和识别状态。
- `fixtures/`：正常、模糊、多题和公式歧义样例。
- `schema.sql`：数据库结构。
- `seed.py`：可复现种子数据。
- `tools.py`：业务工具接口。
- `env.py`：环境装配入口。
- `rollout/`：模型客户端、工具 schema、单任务运行器与轨迹持久化。
- `tools/graph.py`：当前工具依赖图及加权随机游走。
- `tests/`：工具和状态迁移测试。
